A **bank reconciliation** checks why the bank statement and the company’s books show different cash balances. You adjust each balance for timing differences, bank items, and recording errors. The adjusted balances should match.

| Adjustment | Bank balance | Book balance |
|---|---:|---:|
| Starting balance | $8,400 | $7,950 |
| Outstanding cheques: subtract $1,200 | $7,200 | |
| Deposit in transit: add $900 | $8,100 | |
| Bank fee: subtract $50 | | $7,900 |
| NSF cheque: subtract $200 | | $7,700 |
| Cheque recorded as $540 instead of $450: add back $90 | | $7,790 |
| **Adjusted balance** | **$8,100** | **$7,790** |

Outstanding cheques and the deposit in transit are timing differences, so they adjust the bank side. The fee, NSF cheque, and cheque error are missing or incorrect in the books, so they adjust the book side. The error needs a $90 increase because the books reduced cash by $540, but the cheque was only $450.

The adjusted balances differ by **$310**, so the reconciliation is incomplete. Check for another omitted item or an incorrect amount; don’t force the balances to match.
